##### Point Types

* TREE - root of a tree
* AREA - area in a geographic tree
* EQUIPMENT - a program on a controller.  (Not necessarily a physical piece of "equiipment" by the common definition of the term, as a many physical controllers have multiple programs on them)
* BEQU - BACnet equipment instance
* BBI - BACnet Binary Input point
* BAI - BACnet Analog Input point
* BBO - BACnet Binary Output point
* BAO - BACnet Analog Output point
* BTRN - Bacnet Trend object
* BRS - Bacnet Room Sensor
* BSPTCS - some kind of setpoint
* EVT - these appear to be alarms, with EVT standing for "event" - they show up on the logic page as BALM
* LPOINT - I'm not sure what this stands for, but on my system they seem to mostly be network points of various types (ANI, ANI2, BNI, BNI2).  POLLTOT objects (totalizers) show up as LPOINT as well.  It would be good to have a list of these.
* BPID - Bacnet PID Controller
* HSSERV - a link to a remote (probably linked) WebCTRL server
